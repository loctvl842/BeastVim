Select menu: balanced spacing

Same card look, better proportions: a clear gap between the heading and the filter line, equal padding above and below the prompt panel's content, and the footer hints floating evenly with one blank row above and below.

Problem

  • Heading sits right on top of the filter line (glued together).
  • Empty band above the heading (and below the filter): the panel looks empty while its content is cramped.
  • Footer hints sit on the very last line of the card with no padding below, under a tall empty strip: bottom-heavy, footer feels lost.

Scenarios

1 - Opening any select menu
  1. Trigger a code action
    Blank, heading, blank, filter line, blank - clearly separate, equal padding above and below.
  2. Look at the bottom
    Footer hints have one blank row above and one below.
2 - Filtering down to few results
  1. Type a query leaving one option
    Footer keeps the same padding.
3 - Many options (edge)
  1. Open a long menu
    Scrolls as before; footer padding unchanged; whole card stays on screen.
4 - Short terminal (edge)
  1. Open in a short window
    Fewer options if needed; heading, filter and footer keep their padding; nothing cut off.

Behavior rules

  • Prompt panel is exactly: blank, heading, blank, filter line, blank.
  • Footer: one blank row above and one below, always (also in the empty state).
  • Only vertical spacing changes.
  • The card never extends past the bottom of the screen.

Success criteria

  • ☐ Blank row between heading and filter line
  • ☐ Equal one-row padding above the heading and below the filter line
  • ☐ Footer has one blank row above and below
  • ☐ Empty state and single option keep the padding
  • ☐ Tall lists and short terminals still fit
  • ☐ Behavior unchanged

Out of scope

  • Colours, widths, separators, pointer, footer wording
  • Restyling other menus
