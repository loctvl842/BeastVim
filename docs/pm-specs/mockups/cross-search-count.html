Search match counter

Mockup for feedback. Press Enter in the search line below, then n / N to move between matches. A count like 2/3 floats at the end of the matched line and also shows in the statusline.

Click the bottom line to type. The default pattern local starts from line 1, so the first Enter lands on the nearest match after the cursor: 2/3. Try a pattern with no matches too: it shows a toast.
