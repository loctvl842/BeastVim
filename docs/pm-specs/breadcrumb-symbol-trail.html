Symbol Trail

The breadcrumb bar learns to show where inside the file the cursor is: the chain of symbols that contain it, each with a kind icon, right after the file name. Built in, replaces nvim-navic, and also works without a language server.

lua › beast › libs › breadcrumb › init.lua › MM › ƒsetup › ƒensure_autocmds

Panels use letter badges for kind icons; the real bar uses the same icons as the completion menu.

Problem

The bar stops at the file name. The earlier breadcrumb spec promised "code context" after the file, but nothing is drawn there. In a 600-line file, once a function header scrolls off screen, there is no cue for which function, method or class the cursor is in.

Why now: the bar, its per-window behavior and its colors already exist, and the slot after the file name is empty. Filling it closes the gap with nvim-navic without a plugin or a second winbar owner.

Scenarios

1 - Walking through a file
  1. Open a Lua file with a language server; cursor on line 1. Path and file only.
  2. Move into M.setup. Trail: init.lua › M › setup.
  3. Move into a callback inside setup. Trail extends: ... › setup › callback.
  4. Move below the end of M.setup. Trail shrinks to what still contains the cursor.
2 - Language server still starting
  1. Open a file before the server answers. Path and file only.
  2. Server finishes loading. Trail appears by itself, no keypress needed.
3 - Editing while a trail is shown
  1. Type inside setup. Trail stays, never blinks or blanks.
  2. Add a new function above, then pause. Shortly after, trail reflects the new structure.
  3. Rename the function you are in. Once the server catches up, the new name shows.
4 - Two splits on the same file
  1. Split the window; both show init.lua. Same trail in both.
  2. Move the cursor in the left split only. Left trail changes; right trail still matches its own cursor, though unfocused.
5 - Window too narrow
  1. Wide window. Full path, file and all symbols.
  2. Narrow it. Outer directories become "…" first, then outer symbols. File name and innermost symbol always kept.
6 - Turning it off
  1. Set the symbol trail to off in config. Bar behaves exactly as before; no symbol requests are made.
7 - No language server
  1. Open a markdown file with no server. Trail shows headings from the file's structure.
  2. A server attaches later. Trail switches to the server's symbols without a blink.
  3. Open plain text. Path and file only; nothing reported.

Behavior rules

  • The trail is the chain of symbols whose range contains the cursor, outermost first.
  • A cursor on a symbol's own header line counts as inside it. Outside every symbol, nothing is shown.
  • Each window shows the trail for its own cursor, including unfocused windows.
  • Symbols come from the language server when it provides them; otherwise from the file's structure when the language is understood; otherwise path only.
  • The server wins whenever both exist, so the two sources never mix.
  • A symbol with an empty name is skipped; its children still show.
  • Updates happen when the cursor stops moving, so holding j stays smooth.
  • While the server re-reads after an edit, the previous trail is kept rather than blanked.
  • Truncation order: outer directories, then outer symbols. File name, innermost symbol and modified marker are never dropped.
  • Hidden wherever the bar is hidden today. Fully switchable off.

Success criteria

  • Moving into a function, method or class shows its name with a kind icon after the file name.
  • Nested symbols show as an ordered chain, outermost first.
  • Outside any symbol, only path and file name show.
  • Two windows on one file show independent trails.
  • The trail appears by itself once a slow server finishes starting.
  • Typing never blanks the trail; it refreshes shortly after typing pauses.
  • Narrow windows keep the file name and innermost symbol visible.
  • Files with no server but a known language still show a trail, same look.
  • Plain text and unknown languages look exactly as today.
  • Turning the feature off restores today's bar and stops symbol requests.
  • Holding j or k through a large file shows no stutter.

Out of scope

  • Clickable segments and "jump to symbol" menus (separate feature).
  • Filtering symbol kinds and a max-depth setting; width truncation covers long trails for now.
  • Exposing the trail to other bars such as the statusline.
