Preview word diff

In the hunk preview, the exact words that changed get a stronger background than the rest of the line, like GitHub and GitLab. You see the real edit at a glance.

Problem

An edited line shows as a removed line and an added line that are almost identical, each tinted entirely red or green. You must compare them word by word to find the change.

Target behavior

1 - Words added

401 - if not confirmed then
401 + if not confirmed and vim.g.colors_name ~= original then

2 - Word replaced

12 - local count = old_name(x)
12 + local count = new_name(x)

3 - Completely different lines: soft only

30 - foo(a, b)
30 + return bar

4 - Pure addition: soft only

54 local y = 0
55 + local x = 1

Scenarios

1 - Words added to a line

Append a phrase, open the preview: only that phrase is stronger green.

2 - Word replaced

Old name stronger red, new name stronger green.

3 - Staged, then edited again

Compares staged text to current text; emphasis marks only what changed since staging.

4 - Several lines in one hunk

Removed and added lines pair in order; each pair is emphasized on its own.

5 - Unequal line counts

2 removed, 3 added: first two pair up, the extra line is soft green only.

6 - Whole line rewritten

Almost nothing shared: soft highlight only, no striped noise.

7 - Theme change

Emphasis follows the theme and stays visible in dark and light.

Behavior rules

  • Only removed and added lines are emphasized, never context.
  • Lines pair in order within a hunk; unpaired lines stay soft.
  • Emphasis is word-level, grouped, not scattered characters.
  • Pairs sharing too little text skip emphasis.
  • Same in staged and unstaged previews.
  • Two new theme-adjustable highlight groups (removed, added), defaulting to stronger red and green.
  • Syntax colors are kept; only the background changes.
  • Large hunks stay instant; very long lines may skip emphasis.

Success criteria

  • ☐ Appended phrase is the only stronger-green region (matches GitHub).
  • ☐ Replaced word is stronger red then stronger green.
  • ☐ Different lines and pure add/delete stay soft only.
  • ☐ Context lines are never emphasized.
  • ☐ Staged-then-edited emphasizes only changes since staging.
  • ☐ Visible in every bundled colorscheme, dark and light.
  • ☐ No visible delay on a large hunk.

Out of scope

  • Gutter, sign column, or inline emphasis in the main buffer.
  • Sub-word (character) emphasis.
  • A setting to turn emphasis off.
  • Side-by-side layout.
