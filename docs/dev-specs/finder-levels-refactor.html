Finder levels refactor - dev spec

No user-visible change. Split the finder's State into a Session (windows, keys) and a Level (one search), make the pipelines UI-free behind a small host, move format/open/reload behavior onto the source, write the keymaps once, and let the explorer's headless search.lua reuse the same engine. After this, a chained picker is session:push(level) and a new source is one file.

Prerequisite for finder-continuous. Source of truth: docs/dev-specs/finder-levels-refactor.md. Scope you chose: R0 to R5, migrate all sources.

Why refactor first

#Problem (evidence)Effect on the chain
1State builds windows and the search in one constructor (state.lua:56-97)one window set can show only one search
2Pipelines read state.query at call time and call the UI directly (match.lua:39,105,116, stream.lua:61-104)swapping the query lets a late callback corrupt the new one; engine unusable headless
3Behavior chosen by source name in 5 central files (render.lua:40,75,76, action.lua:8,10, autocmds.lua:99, keymaps.lua:15)each new source edits ~12 core files
4Match results are a top-1000 display list, no total, no full set"grep all matching files" has no clean source of truth
5Enter / C-s / C-v written once per pane; copies drifted (list-pane C-v does a split)every new key must be added three times
6search.lua re-implements load + score + generation guard for the explorertwo engines to keep in sync
7Two singletons; only 4 tests open a real finder; none cover reset/reopenno safety net for a lifecycle refactor

Target shape

Research

  • Searched: state/query/view usage per file, name-based dispatch, every finder.open caller (incl. colorscheme cards options and LSP auto-select), search.lua and its single consumer (explorer, 50-assertion test, bench), existing finder tests, earlier finder design docs.
  • Found: engines already key their state by query in weak tables, so they are closer to level-ready than State; gh sources already use the closure-per-create pattern to follow; explorer needs "final scored results only" plus {capped, loading}.
  • Decision: Reuse engines, Query, Filter, matcher, views. Build Session, Level, Host, results fields, source contract + normalizer, key table, test helper.

1. Source contract: a source is one file

Central files stop looking at source.name. Gate: grep -rn 'source\.name' finder/ only matches source/init.lua.

2. Engine and host: pipelines without a UI

---@class Beast.Finder.Host
alive() -> boolean       -- false once its level is stopped / not shown: engines drop late work
render()                 -- query.matched changed
busy(on)                 -- spinner
count(text?)             -- prompt count label
title(text)              -- prompt title
rows() -> integer        -- visible list rows (stream render budget)

-- engine interface, same for match and stream
engine = source.live and pipeline.stream or pipeline.match
engine.start(query, host)     -- match: load items; stream: run once if source.initial_query
engine.run(query, host)       -- prompt changed
engine.reload(query, host)    -- source data changed
engine.abort(query)
engine.matches(query)         -- full match set, nil while still working   (NEW: not just the top 1000)

-- results state on the query (written by the engine, read by anyone)
query.items        -- everything the source produced
query.matched      -- what the list shows (top `query.limit`, default 1000)
query.total        -- how many items match (NEW)
query.loading      -- source still delivering (NEW)
query.matching     -- scorer still running (NEW)

-- inside an engine every deferred callback captures its own query and checks the host
local function stale(s) return s.aborted or not host.alive() end
vim.schedule(function() if stale(s) then return end; query.matched = ...; host.render() end)

3. Session and Level

-- level.lua: one search, no windows
local level = Level.new("live_grep", {
  cwd = root, preloaded_items = nil, files = nil,          -- level-scoped opts
  title = "Live grep",
})
level.source, level.query, level.engine                    -- fixed at creation
level.text, level.cursor, level.offset, level.title        -- what a stack must restore
level:start(host)   level:run(text, host)   level:reload(host)   level:stop()

-- session.lua: windows + keys + autocmds; owns the stack
local session = Session.open("files", { preview = true, layout = nil,
                                        on_preview = fn, on_close = fn, initial_text = "init" })
session.level                 -- current Level (state.query -> session.level.query)
session:push(Level.new("live_grep", { files = paths }))   -- save current, attach new in the SAME windows
session:pop()                 -- stop child, restore parent exactly (prompt, cursor, offset), no search
session:close()               -- one place: aborts every level in the stack, closes windows

-- how a level is bound to the windows (the staleness guard lives here)
function Session:attach(level)
  self.level = level
  local host = {
    alive  = function() return self.level == level and not self.closed end,
    render = function() if self.level == level then render.render(self) end end,
    busy   = function(on) if self.level == level then (on and ui.input.start_spinner or ui.input.stop_spinner)(self.view.input) end end,
    count  = function(t) if self.level == level then ui.input.set_count(self.view.input, t) end end,
    title  = function(t) if self.level == level then ui.input.set_title(self.view.input, t) end end,
    rows   = function() return self.view.list._win_height end,
  }
  level.host = host
  ui.input.set_text(self.view.input, level.text)           -- echo-skipped, no double search
  level:start(host)
end

4. One key table

-- keymaps.lua: written once
local actions = {
  down = function(s) s:move(1) end,           up = function(s) s:move(-1) end,
  confirm = function(s) s:confirm() end,      split = function(s) s:open_in("split") end,
  vsplit  = function(s) s:open_in("vsplit") end,   copy = function(s) s:copy() end,
  close = function(s) s:close() end,          focus_input = ..., focus_preview = ...,
}
local common = {
  { "<C-j>", "down" }, { "<C-k>", "up" }, { "<C-n>", "down" }, { "<C-p>", "up" }, { "<Down>", "down" }, { "<Up>", "up" },
  { "<Tab>", "down" }, { "<S-Tab>", "up" }, { "<CR>", "confirm" }, { "<C-s>", "split" }, { "<C-v>", "vsplit" },
  { "<C-y>", "copy" }, { "<C-c>", "close" }, { "<Esc>", "close", modes = { "n" } },
}
local panes = {
  input   = { modes = { "i", "n" }, extra = { { "<C-h>", "noop" }, { "<C-l>", "focus_preview" } } },
  list    = { modes = { "n" },      extra = { { "<C-h>", "focus_input" }, { "<C-l>", "focus_preview" } }, redirect_printable = true },
  preview = { modes = { "n" },      extra = { { "<C-h>", "focus_input" }, { "<C-l>", "noop" } },         redirect_printable = true },
}
function M.mount(session) for pane, spec in pairs(panes) do bind(session.view[pane].buf, spec, common, actions) end end
-- a new key (e.g. <C-g>) is one line in `common` and works from every pane

5. Headless search on the same engine (explorer client, API unchanged)

-- search.lua (explorer client) after the refactor
function M.files(opts)
  local query = Query(sources.files, { cwd = opts.cwd, limit = (opts.limit or 1000) + 1 })
  local self  = { query = query, closed = false }
  local host  = { alive = function() return not self.closed end,
                  render = function()
                    if self.cb and not query.matching then       -- only final scored results
                      local matched, capped = trim(query.matched, limit)
                      self.cb(matched, { capped = capped, loading = query.loading })
                    end
                  end,
                  busy = noop, count = noop, title = noop, rows = function() return 1 end }
  match.start(query, host)
  function self:query(pattern, cb) query.filter:update(pattern); self.cb = cb; match.run(query, host) end
  function self:refresh() match.reload(query, host) end
  function self:close() self.closed = true; match.abort(query) end
  return self
end
-- explorer code is unchanged: files({cwd}), :query, :refresh, :close

Phases

Each phase is mergeable alone; behavior unchanged; Phase 0 suite stays green. R2 and R3 come before R1 because Level uses them.

Phase 0 - Safety net (R0) risk: low

  1. tests/helpers/finder.lua: shared boilerplate, fake_source, open, press (drives real mappings), rows, wait, windows.
  2. Lifecycle tests: reopen, idempotent close, WinEnter close, reentrant open from on_close, confirmed, initial_text.
  3. Engine tests: match (load, filter, subset, abort) and stream (per-keystroke run, retain, run_when_empty, cancelled callbacks dropped).
  4. Behavior tests: key matrix per pane (today's behavior), per-source formatting/grouping/open/preview, colorscheme cards options, visibility reload.
  5. Baselines: matcher bench, explorer bench, bench-ux.sh all on the starting commit.

Phase 1 - Engines without a UI (R2) risk: high

  1. Query results fields (limit loading matching total), MatchState.total (O(1) counter).
  2. host.lua: Beast.Finder.Host + headless().
  3. Match engine: start/run/reload/abort/matches(query, host), captured query, s.aborted + host.alive() in every deferred callback.
  4. Stream engine: same API; run_id kept; host.busy/count/title/rows.
  5. Old State builds a host and passes (query, host).
  6. Tests with host.headless(): results beyond 1000, late callback ignored, abort mid-load, limit.

Phase 2 - Behavior on the source (R3) risk: medium

  1. Contract + normalize() defaults in source/init.lua.
  2. Migrate all sources: files, buffers, help_tags, colorschemes, live_grep, lsp (x4), gh (x2). format.lua stays the formatter library; the <name>_header and lsp_* aliases go away.
  3. Remove name dispatch from render, action, autocmds, keymaps; list groups by source.group.
  4. Source-contract test over every registered source + static "no name dispatch" gate.

Phase 3 - Session + Level (R1) risk: high

  1. level.lua per pseudo code.
  2. session.lua replaces state.lua: one singleton, attach/push/pop/close, reentrancy guard kept.
  3. Mechanical rename State -> Session, state.query -> session.level.query.
  4. ui/input.set_text (echo-skipped).
  5. Tests: push keeps the same window ids, pop restores prompt/cursor/offset/results without a source call, late callbacks of a popped level ignored, close aborts the stack.

Phase 4 - One key table (R4) risk: medium

  1. Rewrite keymaps.lua as actions + common bindings + per-pane extras.
  2. Only behavior change: list-pane <C-v> opens a vertical split (was a horizontal one). Test updated and called out in the commit.

Phase 5 - Headless search on the engine (R5) risk: medium

  1. Rewrite search.lua; explorer API unchanged; duplicate load/score/generation code deleted.
  2. Verify: test-explorer-search.lua (50 assertions) green, bench-explorer.lua at baseline, manual explorer search on a large repo.

Phase 6 - Docs and wrap-up risk: low

  1. Codemap and finder docs.
  2. Shrink finder-continuous dev spec: its "chain core" phase becomes scoped grep, hint window, keys and the drill field.
  3. Final verification.

Decisions for you

Rename state.lua / State to session.lua / Session. A mechanical but wide rename (annotations in ~8 files). It makes the Session-vs-Level split readable instead of "State, but only half of it". Recommended
Ship push/pop inside the refactor (tested with fake sources, bound to no key). It is the reason for the split and keeps the chain spec small, at the cost of one capability that is not user-visible yet. Recommended
Fix list-pane <C-v> (vertical split) as part of the key-table phase. It is a one-line consequence of writing the key once. Recommended
Keep format.lua as the library of formatters; sources point at them (M.format = format.help_tags) instead of moving 350 lines into each source. Recommended

Testing

  • Headless: Phase 0 suite first and unchanged after every phase; new tests per phase; test-explorer-search.lua; stylua and luals clean.
  • Bench: matcher (Phase 1), explorer (Phase 5), bench-ux.sh all (end), all vs the Phase 0 baseline.

Success criteria

  • Looks and behaves as before everywhere; only difference: list-pane <C-v> is a vertical split.
  • All existing and new tests pass; stylua and luals clean.
  • No source.name dispatch outside source/init.lua.
  • Engines run headless; a late callback of a stopped level changes nothing.
  • engine.matches returns the full match set; query.total is correct.
  • push/pop swap levels in the same windows and restore prompt, cursor, offset, results with no source call.
  • One key table for all panes.
  • search.lua has no private load/score loop; explorer tests and bench unchanged.
  • Benches within noise of baseline.
  • A new source needs no edit outside its own file.
