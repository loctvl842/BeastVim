Select card style - implementation

The list window renders a separator slot above every option (dashed between, solid blue around the selected one), blue bold text and a pointer on the selection, and the footer in a blank bottom border row. The prompt becomes a backing header window with the input overlaid on its filter row. Behavior is unchanged.

PM spec: docs/pm-specs/select-card-style.md

Why now / how

select/ui.lua uses a bordered input joined to the list with ├─┤; select/list.lua shows a bullet and a cursorline tint. The finder already has the slot-row design; select gets its own small copy because its list differs (no grouping, no match highlights, dynamic height).

Research

Reuse: finder's slot scheme and highlight groups as the reference. Use: native float footer (needs a border, so a blank bottom border row), blank borders for padding. Build: header window (floats stack by zindex). BeastSelect* groups are used only inside the select lib.
