Preview word diff

Add a pure word-diff helper, attach its column spans to paired preview rows, and paint them with two new stronger highlight groups over the existing line tint. PM spec: docs/pm-specs/git-preview-word-diff.md.

How it works

Research

Found: diff.lua already wraps vim.text.diff; preview rows, _test seam, extmark namespace and highlight builder exist. No word-level diff anywhere.

Decision: Use vim.text.diff on tokens; Reuse diff wrapper, row pipeline, highlights; Build tokenizer, pairing, span mapping.

Phases

Phase 1 - Word-span helper (no UI change)

  1. Tokenize: word runs, whitespace runs, single punctuation chars, UTF-8 aware. Risk low
  2. word_spans: diff tokens joined by newline, map to merged byte ranges. Risk medium: off-by-one
  3. Cutoffs: skip if a line is over 1000 bytes or under 40% shared non-whitespace (vs the shorter line). Risk low
  4. Tests: appended phrase, replaced word, identical, different, punctuation, whitespace, multibyte, long.

Phase 2 - Paint in the preview

  1. Highlight groups, bg only, blend 0.35 vs line tint 0.15.
  2. Pair rows in build_rows: j-th removed with j-th added; unpaired and context get none. Risk medium
  3. Carry spans: render_rows 5th return, forwarded by open_float. Existing returns unchanged.
  4. Paint: extmark with hl_group, priority 200, per span.
  5. Health + codemap.

Decisions for you

Similarity cutoff: skip emphasis below 40% shared non-whitespace text recommended. Alternatives: 25% (more emphasis, noisier), 60% (cleaner, misses big edits).

Length cutoff: 1000 bytes per line recommended.

Emphasis strength: blend 0.35 recommended, to be tuned by eye across themes.

Testing

  • Manual: PM scenarios 1-7 in NVIM_APPNAME=BeastVim, dark and light themes.

  • ☐ Visible in all bundled themes; no large-hunk delay.
